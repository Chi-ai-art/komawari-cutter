# コマ割りカッター

1枚漫画をコマごとに自動で切り出して、選んだコマだけまとめてダウンロードするツール。
スレッズ（Threads）などで1枚ずつスライド投稿するために作った。

## 公開先

- 公開URL: **https://chi-ai-art.github.io/komawari-cutter/**
- リポジトリ: `Chi-ai-art/komawari-cutter`（**Public**。売り物のプロンプトなど秘密は入っていない。サンプル漫画も入れていない）
- ホスティング: **GitHub Pages**。`main` への push で自動デプロイ（反映は1分ほど）
- 直し方: このフォルダで編集 → `git add -A && git commit -m "..." && git push` だけ

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけ。インストール不要・完全にブラウザ内で処理（画像はどこにも送信しない）。

1. 漫画画像をドロップ（クリックで選択・Ctrl+V貼り付けもOK）
2. 自動でコマを検出して番号を振る
3. いらないコマはクリックして外す／足りない枠はドラッグして追加
4. 「選んだコマをZIPでDL」→ `panel_01.png` … の連番で入ったZIPが落ちてくる

## 切り方は2つ

| 切り方 | 用途 |
|---|---|
| **自動（漫画のコマ割り）** | 1枚漫画。枠線と白いすきまからコマを探す |
| **格子で等分** | スタンプ・絵文字シートなど、等間隔に並んだ画像。よこ×たての数を指定（「自動で数える」で推測も可）。「中身に合わせて余白を詰める」で、1マスごとに絵の外接四角まで詰める |

**透過PNG**を読み込むと、書き出しの「よはくの色」が自動で**「透過のまま」**になる（LINEスタンプ・絵文字の素材そのままの用途）。JPEGは選べなくなる。

## できること

- **自動コマ検出**：2つの方式を組み合わせている
  1. コマの間の白いすきまを見つけて再帰的に分割（XYカット）
  2. 枠線のつながりでコマの塊を見つける（**すきまが1〜2pxしかない絵にも効く**）。1の結果でくっついたまま残ったコマの中を、2でもう一度見直す
  3. 2つの方式は「ページをどれだけ覆えているか」で選ぶ。枠の中が明るい漫画では、すきま方式が枠を突き抜けて小さく切ってしまうため
  4. **枠にぐるりと囲まれているコマは割らない**（3辺以上に、両はしまで届く濃い直線があれば枠とみなす）
  5. **枠線のない所で切ってしまったコマをつなぎ直す**。コマの境目には必ず枠線（両はしまで届く濃い直線）があるはず、という考え方。吹き出しの輪郭は端まで届かないので枠線と区別できる。同じ外枠に囲まれているかも見る（吹き出しの上下で1コマが分断される失敗を防ぐ）
  - 読み順は「左→右」「右→左（日本の漫画）」を切り替え可能
- **微調整**：コマをクリックで選択/解除、**枠のふち（オレンジの取っ手）をドラッグで好きな方向に伸縮**（上下左右の辺＋4隅の8か所）、枠の中をドラッグで移動、何もない所をドラッグで新しい枠を追加、サムネの ✕ で削除
  - 検出が2つに割れてしまったコマは、片方の辺を引き伸ばして1コマにまとめ、余ったほうを ✕ で消す
  - 隣のコマとふちが重なっている所では、ポインタが内側にあるコマの取っ手が優先される
  - **コマを消す**：赤い✕ボタン（キャンバス上）／Delete・Backspaceキー／サムネの ✕。重なっているときは**小さいほうのコマ**が選ばれるので、大きく伸ばした枠の下に隠れたコマも消せる
- **番号は自動**：枠を動かす・伸ばす・足す・消すたびに、読み順で並べ直して番号を振り直す。消しても番号が飛ばない（ZIPの連番もその順）
- **元に戻す**：消した・動かした・伸ばした・足した操作を30回分さかのぼれる（Ctrl+Z も可）
- **枠を追加**：画面に見えているあたりに新しい枠を置く。スマホはこのボタンから（ドラッグで描くのが難しいため）
- **やり直し**：「枠をやり直す」で検出しなおし（手で直したぶんは確認のうえ破棄）、「別の画像にする」で最初の画面へ
- **スライド用の整形**：4:5 / 1:1 / 3:4 / 9:16 / そのまま。余白の色は「コマのふちの色を自動サンプリング」がデフォルトなので、背景になじむ
- **出力**：PNG / JPEG、長辺のpx指定、1コマだけDL（サムネの ⬇）、まとめてZIP

## 調整つまみ

| つまみ | 効くところ |
|---|---|
| コマの間の白さ | この明るさ以上を「すきま」とみなす。背景がうすい色の漫画は値を上げる |
| すきまの細さ | これより細い白帯では切らない。コマ間が狭い漫画は小さく（初期値0.3％＝1086pxの画像で約3px） |
| 小さすぎるコマを無視 | 効果音や飛び出した絵を別コマとして拾ってしまうときは大きく |

## スマホ

- ページ右上に **ver（版）** を出している。スマホの表示が古いと思ったら **「最新に更新」** を押す（オフライン用キャッシュを捨てて取り直す）
- 古いiOS Safari（16より前）には canvas の `roundRect` が無い。描画コードでは使わないこと（2026-09-23 にこれが原因でスマホの取っ手・✕・サムネが全部出なくなった）

- タップ＝コマを選ぶ/はずす。スクロールとは誤爆しない
- 枠の位置やサイズを直したいときだけ「枠をなおす」をオン
- 画面下に固定の操作バー。iPhone / Android では「共有」から写真アプリやスレッズへ直接送れる（Web Share API）
- ホーム画面に追加するとアプリのように全画面で開き、オフラインでも使える（Netlify などに置いた場合）

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ツール本体（1ファイル完結） |
| `manifest.webmanifest` / `icon-*.png` / `apple-touch-icon.png` / `favicon.png` | アイコン。`logo-source.webp`（バナっこがハサミを持っている絵）から生成している。丸く切り抜かれる端末用に `icon-maskable-512.png` は余白を多めにしてある |
| `logo-header.webp` | ページ上部のロゴ（キャラ＋タイトル文字の横並び） |
| `logo-source.webp` | アイコンとロゴの元画像（タイトル文字入りの透過素材） |
| `sw.js` | オフライン用のキャッシュ |
| `sample/*.png` | 検出の確認用（極細すきま・枠内分断・誤分割の再現） |
| `sample/test.webp` | 動作確認用の漫画（gitignore 済み・公開しない） |
