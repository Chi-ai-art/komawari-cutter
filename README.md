# コマ割りカッター

1枚漫画をコマごとに自動で切り出して、選んだコマだけまとめてダウンロードするツール。
スレッズ（Threads）などで1枚ずつスライド投稿するために作った。

## 公開先

- Artifact（スマホでも使える公開版）: https://claude.ai/artifact/RaohqfmE2yPNETJqegoWRy
  - 非公開（自分と共有した人だけ）。ダウンロードは確認ダイアログごしに保存される
  - 更新するときは、このリポジトリの `index.html` を直したあと同じ内容を Artifact 側にも反映する
- ローカル: `index.html` をダブルクリック
- Netlify に本番公開する場合はこのフォルダをそのまま置けばよい（manifest・アイコン・Service Worker 入りで、ホーム画面に追加するとアプリとして開く）

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけ。インストール不要・完全にブラウザ内で処理（画像はどこにも送信しない）。

1. 漫画画像をドロップ（クリックで選択・Ctrl+V貼り付けもOK）
2. 自動でコマを検出して番号を振る
3. いらないコマはクリックして外す／足りない枠はドラッグして追加
4. 「選んだコマをZIPでDL」→ `panel_01.png` … の連番で入ったZIPが落ちてくる

## できること

- **自動コマ検出**：コマの間の白いすきまを見つけて再帰的に分割（XYカット）。読み順は「左→右」「右→左（日本の漫画）」を切り替え可能
- **微調整**：コマをクリックで選択/解除、枠の中をドラッグで移動、角をドラッグでサイズ変更、何もない所をドラッグで新しい枠を追加、サムネの ✕ で削除
- **スライド用の整形**：4:5 / 1:1 / 3:4 / 9:16 / そのまま。余白の色は「コマのふちの色を自動サンプリング」がデフォルトなので、背景になじむ
- **出力**：PNG / JPEG、長辺のpx指定、1コマだけDL（サムネの ⬇）、まとめてZIP

## 調整つまみ

| つまみ | 効くところ |
|---|---|
| コマの間の白さ | この明るさ以上を「すきま」とみなす。背景がうすい色の漫画は値を上げる |
| すきまの細さ | これより細い白帯では切らない。コマ間が狭い漫画は小さく |
| 小さすぎるコマを無視 | 効果音や飛び出した絵を別コマとして拾ってしまうときは大きく |

## スマホ

- タップ＝コマを選ぶ/はずす。スクロールとは誤爆しない
- 枠の位置やサイズを直したいときだけ「枠をなおす」をオン
- 画面下に固定の操作バー。iPhone / Android では「共有」から写真アプリやスレッズへ直接送れる（Web Share API）
- ホーム画面に追加するとアプリのように全画面で開き、オフラインでも使える（Netlify などに置いた場合）
